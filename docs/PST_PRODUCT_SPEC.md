# PST Product Specification

PST Factory turns a specific problem, method, knowledge, reusable tools, and AI
assistance into a structured Problem-Solving Toolkit product.

## MVP promise

An administrator can define a problem, user, and outcome; ask PST Architect for a
proposal; review and edit a Blueprint; assemble reusable assets; preview and simulate
the experience; run QA; explicitly approve; publish; and open the resulting guided
customer workspace.

## Product DNA

- **Problem**: the specific user problem being solved.
- **User**: the target person.
- **Journey**: the guided path from starting context to outcome.
- **Components**: only the building blocks needed by the outcome.
- **Intelligence**: human-reviewed AI assistance and rules.
- **Outcome**: the observable result the user should reach.

AI proposes. A human approves. A project with blocking QA errors cannot be published.

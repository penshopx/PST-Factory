# PST Factory Lifecycle

The conceptual lifecycle is:

`DISCOVER → DEFINE → ARCHITECT → BLUEPRINT → ASSEMBLE → SIMULATE → QA → APPROVE → PUBLISH → MEASURE → LEARN → IMPROVE`

The MVP implements the central manufacturing path:

`DEFINE → ARCHITECT → BLUEPRINT → ASSEMBLE → PREVIEW → QA → APPROVE → PUBLISH`

Every major transition creates a factory event. QA reports PASS, WARNING, or ERROR;
blocking ERROR results cannot enter the approval/publish path.

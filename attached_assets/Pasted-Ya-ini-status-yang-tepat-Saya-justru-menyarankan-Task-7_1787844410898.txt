## Acceptance Gate Task #7

Saya sarankan Replit nantinya tidak boleh menyatakan Phase 1 berhasil hanya karena unit test hijau.

Harus lulus **5 gate**:

### Gate 1 — Security

```text
User
 ↓
Workspace
 ↓
Role
 ↓
Permission
 ↓
Resource
```

Tidak boleh ada cross-workspace access.

### Gate 2 — Manufacturing Intelligence

```text
Problem
 ↓
Pattern
 ↓
Recipe
 ↓
Blueprint
```

Pattern dan Recipe **harus benar-benar memengaruhi Blueprint**.

### Gate 3 — Configuration

```text
PST A configuration
        ↓
    behavior A

PST B configuration
        ↓
    behavior B
```

Tidak boleh ada:

```text
if PST === "Cashflow"
if PST === "Decision"
```

### Gate 4 — Runtime

Customer harus benar-benar mengalami perbedaan perilaku, bukan sekadar:

> judul step berbeda.

Harus bisa berbeda dalam:

* input;
* pertanyaan;
* scoring;
* workflow;
* output.

### Gate 5 — Regression

Semua kemampuan MVP sebelumnya tetap berjalan.

# Dan ada satu tes yang saya anggap paling penting

Nanti di Task #7, jangan hanya menggunakan dua PST yang sudah ada.

Buat **PST #003** yang sengaja berbeda.

Misalnya:

### Document Compliance Check

```text
FILE UPLOAD
 ↓
DOCUMENT EXTRACTION
 ↓
CHECKLIST
 ↓
COMPLIANCE SCORING
 ↓
GAP ANALYSIS
 ↓
REPORT
```

Bandingkan:

### Cashflow

```text
INPUT
→ QUESTION
→ SCORING
→ DIAGNOSIS
→ RECOMMENDATION
```

### Decision

```text
OPTIONS
→ CRITERIA
→ SCORING
→ COMPARISON
→ RECOMMENDATION
```

### Document

```text
FILE
→ EXTRACTION
→ VALIDATION
→ SCORING
→ REPORT
```

Kalau ketiganya dapat dibuat **tanpa menulis logic khusus produk**, itu jauh lebih kuat daripada sekadar dua contoh.
